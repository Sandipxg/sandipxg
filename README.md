### 🛡️ SafeX — Crypto Wallet
> *Zero-Trust Self-Custodial Web3 Vault*

[![Repository](https://img.shields.io/badge/📦_Repository-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/Sandipxg/SafeX--Crypto-Wallet)
[![Case Study](https://img.shields.io/badge/📑_Case_Study-sandip.codes-0ea5e9?style=for-the-badge)](https://sandip.codes/projects/safex-crypto-wallet)

An enterprise-grade, 100% non-custodial multi-chain crypto wallet built from fundamental cryptographic primitives with zero central database trust.

#### Key Architectural Highlights:
- **Argon2id Memory-Hard KDF & AES-256-GCM**: Client-side vault demanding 64 MB dedicated RAM per hash, thwarting GPU brute-forcing.
- **Active RAM Zeroization**: Ephemeral memory handles wiped via `buffer.fill(0)` on tab timeout or lock.
- **Multi-Chain Derivation**: BIP-39 entropy to EVM (BIP-44) and Bitcoin Native SegWit (BIP-84 Bech32).
- **Offline EIP-1559 Signing**: Raw bytecode serialized and signed on-device before JSON-RPC broadcast.
- **Uniswap V2 AMM Swaps**: Constant-product routing (`x · y = k`) with slippage bounds.
- **Resilient Multi-Provider RPC**: Zero-downtime automated failover across public RPC nodes.

**Stack**: `React` `Node.js` `TypeScript` `PostgreSQL` `viem` `Redis` `Tailwind CSS`

### 💬 ChatApp
> *Real-Time E2EE & WebRTC Communications Platform*

[![Live Demo](https://img.shields.io/badge/🌐_Live_Demo-Visit_App-10b981?style=for-the-badge)](https://chat-app-gold-kappa-51.vercel.app/)
[![Repository](https://img.shields.io/badge/📦_Repository-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/Sandipxg/ChatApp)
[![Case Study](https://img.shields.io/badge/📑_Case_Study-sandip.codes-0ea5e9?style=for-the-badge)](https://sandip.codes/projects/chatapp)

A production-ready real-time communication platform engineered for end-to-end privacy, low-latency audio/video calling, and persistent sessions.

#### Key Architectural Highlights:
- **End-to-End Encryption (E2EE)**: Asymmetric ECDH (P-256) key exchange combined with AES-GCM-256 payload scrambling.
- **WebRTC Voice & Video**: P2P signaling via Socket.IO, picture-in-picture stream, live mute/unmute, and screen-sharing.
- **Sub-50ms Socket.IO Sync**: Instant message dispatch, live typing indicators, online presence, and reactions.
- **30-Day Session Persistence**: Better Auth configured with Partitioned cookies and instant localStorage cold start.
- **Offline Resilience**: IndexedDB JWK serialization and Service Worker message queuing.

**Stack**: `React` `Node.js` `TypeScript` `Socket.IO` `MongoDB` `WebRTC`

### 📓 MyJournalApp
> *Offline-First Progressive Web App*

[![Live Demo](https://img.shields.io/badge/🌐_Live_Demo-Visit_App-10b981?style=for-the-badge)](https://my-journal-app-sigma.vercel.app/)
[![Repository](https://img.shields.io/badge/📦_Repository-GitHub-181717?style=for-the-badge&logo=github)](https://github.com/Sandipxg/MyJournalApp)
[![Case Study](https://img.shields.io/badge/📑_Case_Study-sandip.codes-0ea5e9?style=for-the-badge)](https://sandip.codes/projects/my-journal-app)

A personal journaling PWA designed to work effortlessly without an internet connection, featuring an autonomous synchronization pipeline.

#### Key Architectural Highlights:
- **Queue Compaction Engine**: Intercepts offline operations in IndexedDB, intelligently collapsing duplicate writes before server dispatch.
- **Temporary ID Resolution**: Seamlessly reconciles client-side temporary keys into server MongoDB ObjectIDs with zero UI flicker.
- **Anti-Lockout Cache Handling**: Custom Network-First SWR pipeline for documents preventing blank screens on new bundle releases.
- **Dynamic Chunk Recovery**: React ErrorBoundary catching chunk load failures on offline navigation.
- **Push Notifications & Reminders**: Native background Web Push (VAPID) and automated reminder notifications via Node-Cron.

**Stack**: `React` `Node.js` `MongoDB` `IndexedDB` `Service Workers` `Docker`
